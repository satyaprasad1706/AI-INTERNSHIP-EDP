# Week 1: Data Cleaning with Pandas

Hey! Here are my personal notes & takeaways from Week 1 of the EDP Internship.

### Things I Learned

1. **Loading Data (`pd.read_csv`)** - Bringing CSV files into Python tables.
2. **First Look (`head()` / `tail()`)** - Peeking at the top & bottom 5 rows to check structure.
3. **Checking Size (`shape`)** - Knowing total rows & columns (`53,940` rows in `diamonds.csv`).
4. **Data Types (`info()` / `dtypes`)** - Making sure numbers are actually read as numbers, not text.
5. **Quick Stats (`describe()`)** - Getting average, min, and max values in 1 second.
6. **Spotting Missing Data (`isnull().sum()`)** - Finding empty or blank cells.
7. **Cleaning Column Names (`rename()`)** - Changing messy titles like `Annual Income (k$)` to `Annual_Income`.
8. **Removing Duplicates (`drop_duplicates()`)** - Kicking out duplicate rows so data stays accurate.
9. **Exporting (`to_csv(index=False)`)** - Saving clean data without adding extra index numbers.
10. **Re-testing Files** - Loading saved files back into Pandas to confirm everything works.
